Pero con javascript se modificó y permitió que sea responsable tanto en apps como en la información que estaba en la pagina

HTML5 unificó HTML, CSS y JavaScript al actuar como un estándar centralizado que integra la estructura, estilo y comportamiento avanzado en una sola plataforma, eliminando la dependencia de plugins externos (como Flash). Permite a las tres tecnologías trabajar cohesivamente para crear sitios web rápidos, interactivos y adaptables (responsive). 
Estructura y Semántica (HTML): Define la estructura con nuevas etiquetas (ej. <article>, <nav>) y soporta funciones multimedia nativas como <video> y <audio>.
Presentación y Estilo (CSS): HTML5 interactúa estrechamente con CSS3 para mejorar el diseño y la estética, permitiendo animaciones y layouts complejos sin necesidad de herramientas externas.
Comportamiento y Funcionalidad (JavaScript): Integra APIS de JavaScript avanzadas que añaden interactividad compleja, almacenamiento local, dibujos 3D y mapas, todo nativamente en el navegador.
